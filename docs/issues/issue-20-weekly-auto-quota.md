# 【审查·AI·可用性·低】周报每日自动生成名额被「无数据」类暂时性失败消耗（#42）

- 级别：低 ｜ 轴：Spec ｜ 规格出处：CONTEXT.md:76 / issue #42「打开应用即有：无缓存则启动后自动后台生成一次」
- 位置：`src/renderer/app.js:917-921`（发起前先落 `weeklyAutoDay = today`）；`src/main/ipc.js:519-521`（「近 7 天没有提交活动」失败分支）

## 问题

自动生成名额在发起前即消耗：首启或扫描尚未落地时 `doAiAsk` 以「近 7 天没有提交活动」失败，当天名额已用掉，扫描完成后 onTick 重估被 `weeklyAutoDay` 挡住，当天不再自动重试，只能手动点。同理「早上无提交自动生成失败 → 白天有了提交」也不补。

## 方案

`weeklyAutoDay` 改为「成功后才落」；或对失败原因分类——「无数据」类暂时性失败不消耗名额（可在 IPC 错误里带 code 区分）。

## 验收

首启扫描未完成 → 自动生成失败 → 扫描落地后当天内 onTick 能自动补生成一次。
