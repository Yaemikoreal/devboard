常见问题

我的代码会被上传吗？

不会。扫描与存储全部在本机完成；AI 功能只发送统计数字与提交信息文本，不含代码内容，设置里可整体关闭。

AI 功能需要什么条件？

本机安装并登录任一 Agent CLI（claude / codex / kimi / grok 或自定义命令）即可；没装也不影响其他功能，AI 入口自动隐藏。

怎么唤出看板？

默认 Ctrl+Shift+D，可在设置里改成任意组合；点托盘图标也行。

项目分散在不同目录怎么办？

设置里支持多个扫描根目录、单个补充路径与黑名单，照常聚合。

收费吗？

完全免费，MIT 开源。觉得好用，去 GitHub 点个 Star 就是最大的支持。

支持 macOS / Linux 吗？

目前发布 Windows 版；基于 Electron 构建，其他平台可克隆仓库从源码运行。
